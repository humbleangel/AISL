Born 1993, NT. A fresh VMS-influenced kernel keeping DOS/Win32 compatibility on top. 1969, Bell Labs. Thompson & Ritchie; portable OS plus the C language, bootstrapped from nothing. 2026, from scratch. Replays the Unix bootstrap honestly: hand seed → tiny assembler → self-hosting system.
Kernel idea Objects with access lists, async I/O — sound core buried under Win32 accretion. Small core, everything-is-a-file, processes that fork. Elegant once, frozen since. One address space, pinned tasks, no processes to fork and no files to parse.
Language vs system Two worlds: apps speak Win32/.NET, the kernel speaks its own tongue. A translation layer forever between. Two worlds: C programs on one side, syscalls on the other. The split every Unix inherits. One thing. The language and the system are the same artifact — no translation layer to betray either side.
Who may do what Users, groups, Administrator — ambient powers attached to who you are, scattered across registry, policies, and file flags. Users, root, mode bits — whoever holds the name holds the power; root can do anything, silently. Nothing ambient. Every access presents an explicit hardware-bound capability; there is no root.
Files Drive letters, backslashes, registry plus INI plus XML — several truths about configuration, none complete. A single tree of bytes with paths. Simple, universal — and the reason everything must be parsed, forever. No files, no paths, no file descriptors. Persistent typed objects addressed directly, never parsed.
Tasks Processes and threads with shared everything; preempted anywhere, at any time. Processes that fork; threads sharing memory; the scheduler may interrupt anyone mid-thought. One pinned task per core, running to completion. Nothing arrives unasked; interrupts are messages, not theft.
Calling the kernel Hundreds of syscalls plus a fast-call ABI — the largest attack surface, kept for compatibility. A table of syscalls every program must know; the boundary every exploit crosses. No syscalls at all. Crossing is a checked call; faults are the normal path, not the exception.
Time One wall clock everybody trusts — until daylight saving, NTP jumps, or virtualization prove otherwise. One wall clock plus timers; causality left to whoever asks. No global now. Causality ticks forward only when messages are sent; wall time is an outward-signed estimate, never truth.
Who vouches Signatures and vendors vouch — which attests who signed, never whether the bytes match the source. Permissions and package managers vouch — same gap one level down. Nobody vouches alone. Diverse rebuilds plus measured pages plus outward quorum — trust is a verdict, never a claim.
What survives a crash Whatever the filesystem journal happened to flush — torn writes presented as committed. Whatever fsync actually reached the disk — frequently less than promised. Only crash-consistent appends. Power loss is the normal case, not the emergency; resume is the only boot.
Old software Must run: thirty years of binaries, drivers, and quirks carried forever. Compatibility is the product. Must run: POSIX is a promise that can never be broken, only extended. May not run. No compatibility layer, no legacy drivers, no POSIX — forgetting is a feature.
Openness Closed core, open ecosystem of apps — open where it sells, closed where it counts. Open core, open ecosystem — and Apple proves the same core can be dressed into a closed garden. Open process: public bootstrap log from hand-checked seed to reproducible build. Nothing to take on faith.
When it breaks Blue screen, error codes, event logs — failure as paperwork after the fact. Errno, signals, core dumps — failure as a number nobody reads. Failure as design material: compiler betrayal, silent corruption, power loss, and stolen time each have a named detector first.
How it changes Vendor ships, users accept. Intent flows one way — down. Maintainers merge; distributions package. Intent negotiated in mailing lists. One holder, expiring lease, machine dissent first, human last. Only sealed intent-diffs merge — never code floods.
Guiding principle Don't break the customer. Do one thing well — then keep it forever. Don't fight the CPU: use its instructions intelligently to build the first tool.
Built first for Every desktop, by default. Every server, by default. One signing vault: the place whose keys stay unstealable even by malicious hardware.
