# Decision brief 21/28 (cross-cutting) — SMI posture

RECOMMENDATION: DISSENT (pure, no local fault threshold). Local rule: NEVER fault, trap, abort, or retry on SMI footprint. On slice exit (or timer tick), sample SMI_COUNT+TSC+APERF+MPERF bracket, compute skew, attach as dissent-weight vote to quorum record, repair monotonic clock (effective = TSC − estimated-stolen), continue. Quorum rule: skew is one vote — correlate across nodes/slices (isolated outlier + large ΔTSC−ΔMPERF with ΔSMI_COUNT>0 = suspect firmware/compromise, quarantine via existing Byzantine path; fleet-correlated small skews = routine SMM, ignore; ΔSMI_COUNT=0 + skew = thermal/DVFS, ignore for SMI purposes).

## THINK-1 (from metal)
SMI is not an interrupt — it is a mode switch: CPU finishes instruction boundary, saves full state to SMRAM, asserts SMIACT#, all cores rendezvous, executes firmware, RSM restores. OS/hypervisor sees nothing except lost time. CLI, IDT, CR, EPT, VMX controls — none trap it. NMI included: SMI beats NMI. So FAULT model claims "trap synchronously into handler" — physically impossible at entry. Best you can do is post-RSM inference: TSC advanced but your slice didn't. That's not a trap, that's an autopsy. Calling it synchronous corrupts AISL's fault semantics: faults must be attributable, timely, and handler must be able to make progress — none hold (attribution statistical: thermal/DVFS/IRQ/NMI/C1E all look like steal; timeliness after-the-fact: firmware already ran, registers already touched; progress unachievable: cannot preempt, bound, or retry SMM). DISSENT fits: each slice's TSC-APERF/MPERF-SMI_COUNT skew as signed observation, quorum decides outlier/malicious vs routine. Local node never faults itself for firmware's sin.

## HARDWARE FINDINGS (x86-only, web)
- SMI entry/exit, priority: SMI via SMI# pin/APIC, unmaskable by CLI/IF, independent of IDT, takes precedence over NMI/debug/external IRQ; CPU waits for instruction/store boundary, saves context to SMRAM, all cores must enter before any handler runs; only exit is RSM (0F AAh), illegal outside SMM. Source: OpenSecurityTraining IntroBIOS SMM Internals (Intel SDM-derived).
- MSR_SMI_COUNT 0x34: Nehalem+ only, read-only free-running count of SMIs since boot, per-package; pollable via rdmsr/turbostat; counts entries, says nothing about cycles stolen; SW SMI inducible via port 0xB2/0xB3 (chipset-dependent). Sources: above PDF Ch.35 note; StackOverflow SMM-occurred (turbostat excerpt); LKML perf SMI_COUNT patch; smackerelofopinion Detecting SMIs.
- TSC vs APERF (0xE8)/MPERF (0xE7) steal signal: TSC invariant monotonic counts in all P/C-states including stolen time; APERF/MPERF count only in OS-visible C0; turbostat Busy% = ΔMPERF/ΔTSC, BzyMHz = base × ΔAPERF/ΔMPERF; SMM depresses Busy% (TSC advances, MPERF doesn't) — usable as skew detector but confounded by turbo/throttle/forced-idle/MWAIT/HLT and bus-vs-crystal drift (~1%). Sources: intel/pepc docs/misc-tsc-amperf.md; Linux aperfmperf.c.
- STM/TXT constraint: only de-privilege path is SMI Transfer Monitor (SMM hypervisor hosting BIOS handler in VM, EPT/IO/MSR bitmaps enforce MLE policy). Hard limits: requires BIOS opt-in (IA32_SMM_MONITOR_CTL 0x9B VALID+MSEG, set only from SMM, identical on all threads) AND MLE opt-in (header bit, GETSEC[SENTER] masks SMIs until STM starts); BIOS Required-Resource list always wins (must honor, must refuse MLE protection conflicting with it); default SMI-guest policy allow-unless-denied; violation without BIOS exception handler = system reset. Commodity firmware rarely provisions MSEG/STM. Sources: Intel STM User Guide 819978; Delgado HASP'20; Intel Tour Beyond BIOS.
- NMI: still maskable-in-effect (blocked until IRET), trappable via IDT, lower priority than SMI. So NMI can be a fault; SMI cannot.

## THINK-2 (after findings)
Findings confirm THINK-1 and kill FAULT harder than expected: detectability is count-without-duration (SMI_COUNT) plus noisy duration-without-cause (TSC-MPERF gap) — no cycle-stolen MSR exists (2013 wish still unfulfilled). Threshold cannot separate 150µs fan-control SMI from 150µs thermal dip or IRQ storm. False-positive fault = self-DoS; attacker with SW-SMI access (0xB2) turns your fault handler into a remote kill switch. Handler feasibility nil without STM, and STM needs hostile-party (BIOS vendor) cooperation + BIOS wins conflicts by spec — AISL cannot mandate MSEG on commodity x86-64. Designing FAULT assuming STM = fighting CPU + supply chain. Quorum latency objection dissolves: SMI rate is Hz-scale, so async post-slice vote costs nothing on hot path. Local slice needs monotonic-clock repair, not judgment. Only legitimate local action is accounting: log triple (ΔTSC, ΔAPERF, ΔMPERF, ΔSMI_COUNT), re-anchor language time, mark slice time-tainted. Not HYBRID — no control-flow branch on the observation; any local fault threshold reintroduces false-positive trap path.

## REASONS
Matches physics (inference-only input → vote, not trap); preserves fault-soundness (faults stay attributable+actionable); denies SW-SMI DoS amplifier; needs no BIOS cooperation; Thompson-consistent (untrusted firmware stays outside TCB, observed statistically).

## PROVING EXPERIMENT (one rig, ~1 day)
Calibrated-loop discriminator on 1 Nehalem+ box: pin slice, loop RDTSC+RMSR(APERF,MPERF,SMI_COUNT) brackets at 1kHz. Phase A: inject ground-truth SMIs via port 0xB2 writes. Phase B: inject confounders (thermal throttle via stress+turbo, IRQ flood, MWAIT idle). Plot ΔTSC−ΔMPERF distributions for A vs B at fixed ΔSMI_COUNT. Success for DISSENT: overlap >5% (no threshold achieves <1e-6 false-positive fault rate) AND 3-node replay shows quorum outlier rule separates injected-long-SMM node from controls. One logic-analyzer-free afternoon with msr-tools+turbostat.

## WHAT WOULD CHANGE MY MIND (to HYBRID with exact split)
Any ONE: (a) zero-false-positive synchronous signal demonstrated (SMI_COUNT increment always paired with bounded attributable stall, e.g. SMM duration hard-capped <10µs on all AISL-target boards); (b) STM universally provisioned with MLE-wins policy (spec change + fleet measurement showing MSEG active and BIOS list empty of DRAM covering AISL); (c) new silicon MSR reporting SMM cycles-stolen synchronously with trap-enable bit. Until then, FAULT is fiction and HYBRID is FAULT with a mustache. Skipped: STM mandate, local SMI fault handler, APERF-only threshold — add when silicon/firmware gives synchronous attributable signal.
