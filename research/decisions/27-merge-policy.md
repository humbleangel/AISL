# Decision brief 27/28 (cross-cutting) — merge policy mechanics

RECOMMENDATION: MACHINE-GATE-FIRST → INTENT-DIFF-ONLY → QUORUM-LAST. All fail-closed. No bypass lane. Exact pipeline: 1. INGRESS (sealed intent-diff shape required; no seal / oversized / code-without-intent = auto-reject, never queued; over-cap shed new with 429 + backoff — format only, not review). 2. MACHINE-GATE (proposer-independent runners only; all verdicts — build, tests, policy, DDC/diverse rebuild, sigs — must be GREEN; any RED, missing attestation, or timeout = DROP, no human sees it; over-cap shed, never skip; proposer never supplies its own PASS). 3. COMPARATOR (proof that merged artifact corresponds exactly to sealed intent diff; mismatch, unproved bytes, timeout = DROP; code flood never merges directly, only via proven diff). 4. QUORUM (live humans judge survivors only; no quorum within T = NO MERGE; any unresolved principled dissent = NO MERGE, must re-propose new intent diff; over-cap bounded queue, oldest shed back to re-propose, never batch-approve). No emergency human override of stages 2–3; emergency is a new sealed intent diff through same pipe.

## THINK-1 (bandwidth + trust)
Bandwidth is binding: humans ~1–10 diffs/day of real review; machines ~10k/day. Any pipeline spending human attention before machines shed load is DoS-able by flood. Bun lesson + Thompson 1984 together: proposer floods, reviewer rubber-stamps, proposer never grades itself. The three candidates are stages in wrong order if taken alone: QUORUM-THEN-DIFF first pays scarcest resource (live quorum convening + context-switch) on unfiltered input (attacker cost to convene defenders ≫ attacker cost to propose; liveness dies or quorum batch-approves = fail-open). INTENT-DIFF-ONLY alone solves flood shape but not correctness (sealed intent + comparator proof still needs someone to run comparator on a machine the proposer doesn't control — otherwise Thompson-collusion: poisoned toolchain attests its own output). MACHINE-GATE-FIRST alone solves triage but not merge semantics (passing tests/build/lint ≠ proof diff does only what intent claims; code flood passing CI still merges). Thompson-collusion forces: verdict machine ≠ proposer machine, comparator independent, no self-grading. Bandwidth forces: machines before humans, quorum last only on survivors. Liveness risk of all-fail-closed (deadlock on flaky CI, missing quorum, dissent veto) handled by explicit shed/retry, not fail-open bypass.

## THINK-2 (after skip-note)
Correct order is a stack, not a choice: 0. Shape admission (cheap, stateless) → 1. Machine-gate (expensive, untrusted-proposer) → 2. Intent-diff + comparator proof (binding) → 3. Quorum (scarce human judgment on survivors only). Intent-diff appears twice deliberately: shape-check at ingress costs almost nothing and prevents CI-DoS; semantic proof after machine-gate binds code to intent before any human looks. Prior lean (machine-gate → intent-diff → quorum) is right, with shape pre-filter made explicit. Fail-closed default at every transition, liveness via shed/retry never bypass: over-cap cannot escalate privilege; timeout cannot equal pass; dissent cannot be outvoted by fatigue.

## REASONS
Only order protecting bandwidth (humans see <1% of proposals), defeating self-grading (Thompson needs independent gate+comparator before trust), and keeping liveness via shed/retry rather than fail-open.

## PROVING EXPERIMENT (operability drill, quarterly)
Flood + poison drill: inject (a) 100× code-flood with no intent, (b) 1 valid fix as sealed intent diff, (c) 1 Thompson-poisoned toolchain self-attesting PASS with hidden payload. Pass: (a) rejected at ingress/gate with zero quorum minutes; (b) ONLY item reaching quorum and merging; (c) caught at independent rebuild/comparator, never reaches quorum, alert fires. Measure human minutes consumed, gate shed count, time-to-merge for (b). Fail pipeline if any human saw (a)/(c) or (c) merged.

## WHAT WOULD CHANGE MY MIND
(1) Measured machine-gate false-negative on real poison > human catch rate on survivors → add second diverse comparator before quorum. (2) Quorum starvation blocks critical fix > defined SLO while gate GREEN → bounded pre-declared break-glass requiring retroactive quorum + auto-revert on dissent, never silent bypass. (3) Comparator cost > human review cost at current scale → shrink allowed diff size further rather than dropping proof.
