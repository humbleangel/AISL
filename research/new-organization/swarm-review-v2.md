# Swarm review v2 — new-organization (additive, non-destructive)

Original v1 sublist kept as folders. This file adds the swarm audit.

## Judgment of v1
- two-plus-swarm: vague headcount magic, still assumes humans scale output when generation is free and review is the only bottleneck.
- intent-holding-human: right Bun-lesson instinct but solo holder is bus-factor suicide and overlaps two-plus-swarm.
- public-bootstrap-log: right Thompson moral but shallow as blog-theater without reproducible seed + attestation.
- adversarial-review-default: suicidal verbatim — human adversarial review on everything collapses the exact bandwidth we must protect.
- single-image-ownership: strongest of six, fights Unix committee-fork drift, but fails if owner becomes manual bottleneck without oracle gate.
- classroom-contributors: 80-year open-source feel-good that floods scarce review with novice diffs unless fully sandboxed.

## Completed sublist v2
- dual-intent-core: two humans hold intent so review never stalls, matching few-strong-cores metal without committee drift.
- oracle-gated-merge: independent VT-x emulated test oracle must go green before any human looks, spending review only on intent not bugs.
- ringed-trust-lanes: mirror x86 rings in org — ring-0 mergers, ring-1 vetted agents, ring-3 untrusted — faults stay in user-mode, never touch image.
- single-image-owner: one merger for one releasable OS+language image keeps review queue linear and kills fork fragmentation.
- attested-bootstrap-log: append-only NVMe public log from hand-checked seed to reproducible build with TPM anchor answers Thompson without re-reading every diff.
- machine-adversary-first: agent swarm red-teams every diff SIMD-parallel before human sees it, making adversarial review cheap not bandwidth-fatal.
- sandbox-classroom-track: novices build in paging-isolated sandboxes with oracle-only feedback, learning without taxing release review.
